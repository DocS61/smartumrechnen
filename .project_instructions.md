# SmartUmrechnen - Project Instructions

## Project Overview
German unit converter web app (smartumrechnen.de) with 15 categories: Länge, Gewicht, Temperatur, Währung, Fläche, Volumen, Geschwindigkeit, Kleidergrößen, Schuhgrößen, Kochmaße, Vitamine, Datengrößen, Kraftstoffverbrauch, Druck, Leistung.

## Tech Stack
- Next.js 14, Tailwind CSS, Lucide Icons, Recharts
- PWA with Service Worker (sw.js, cache: smartumrechnen-v1)
- Dynamic OG images per page

## Visual Style
- Primary color: Blue (#0ea5e9 / sky-500)
- Clean, minimal design with card-based layouts
- German language throughout (all UI text, labels, descriptions)
- Responsive grid layout for category cards

## Architecture
- `/app/page.tsx` - Homepage with metadata
- `/app/umrechner/[slug]/page.tsx` - Dynamic converter pages
- `/components/home-content.tsx` - Homepage client component
- `/app/umrechner/[slug]/_components/converter-page.tsx` - Converter page client component
- `/lib/seo-content.ts` - SEO data (explanations, tables, FAQs, formulas) for all 15 categories + homepage
- `/components/seo-content-section.tsx` - SEO display components (ExplanationSection, ReferenceTable, FAQSection, PopularConversions)

## Page Layout
### Homepage
Hero → Ad → All Categories Grid → Popular Conversions → Ad → FAQ (with JSON-LD) → Country Presets + History → Footer

### Converter Pages
Header → Converter → Comparison Chart → SEO Content (Explanation + Reference Table) → Ad → FAQ (with JSON-LD) → Ad → Related Converters → Footer
- **No CountryPresets on converter pages** (user explicitly requested they stay only on homepage)

## Shared Constants
- `/lib/constants.ts`: Contains `COMPOUND_NAMES` (grammatically correct German compound names) and `RELATED_CATEGORIES` (semantic groupings for "Related Converters" suggestions). Both are imported by converter pages instead of duplicated.

## Critical Design Decisions
### Animations REMOVED
- ALL CSS animations have been stripped from `animate.tsx` (FadeIn, SlideIn, Stagger, StaggerItem are now pure pass-through wrappers)
- ALL custom animation keyframes removed from `tailwind.config.ts` (only accordion animations remain)
- Reason: CSS animations with `opacity: 0` initial state caused SSR content to be invisible. Combined with Service Worker caching old HTML, this created a persistent visibility bug. Removing animations permanently prevents this class of bugs.
- `framer-motion` is still in package.json (used only in task-card.tsx) but NOT used on main pages

### Service Worker Caching
- sw.js caches pages in `smartumrechnen-v1` cache
- When making changes that affect SSR HTML, be aware the SW may serve stale content
- Always test with hard refresh (Ctrl+Shift+R) or clear SW cache when debugging visibility issues

## SEO Features
- Dynamic OG images for homepage and all converter pages (using ImageResponse)
- FAQ sections with JSON-LD FAQPage schema markup
- Explanatory content with formulas and reference tables per category
- Vitamin page specifically explains IU (International Units) and why only certain vitamins have IU conversion
