# SmartUmrechnen - Projektübersicht

## Beschreibung
Professionelle Umrechner-Website (smartumrechnen.de) mit 15 Kategorien, komplett auf Deutsch.

## Technische Architektur
- Keine Datenbank - alles über localStorage
- Frankfurter API für Währungskurse (kostenlos, kein API-Key)
- recharts für Visualisierungen
- PWA mit Service Worker
- SEO-optimiert mit strukturierten Daten

## Farbpalette
- Primary: Teal/Blaugrün (#0EA5E9 / hsl 199 89% 48%) - professionell, vertrauenswürdig
- Dark mode unterstützt
- Accent: Emerald für Erfolg, Orange für Highlights

## Seitenstruktur
- `/` - Homepage mit Kategorien-Grid, Smart-Vorschläge, Verlauf
- `/umrechner/[slug]` - Dynamische Umrechner-Seiten (15 Kategorien)
- Sticky Header mit Navigation
- Kein Footer mit unnötigen Links

## 15 Umrechner-Kategorien
laenge, gewicht, temperatur, waehrung, flaeche, volumen, geschwindigkeit, kleidergroessen, schuhgroessen, kochmasse, vitamine, datengroessen, kraftstoffverbrauch, druck, leistung

## Features
- localStorage: Verlauf + Favoriten
- Smart-Vorschläge basierend auf Nutzungsverhalten
- Umrechnungsketten: Mehrere Einheiten gleichzeitig
- Länder-Presets (USA, UK, etc.)
- Visualisierungen mit recharts
- AdSense-Platzhalter
- PWA + Offline-Modus
